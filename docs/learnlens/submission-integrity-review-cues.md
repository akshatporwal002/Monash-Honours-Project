# Submission-linked academic integrity review cues

PD6 requires repeated answer-only requests and copied-solution signals to become proportionate review cues, with a redirect to reasoning and no automatic finding or penalty. This delivery extends the dialogue-only boundary recorded in `learner-typed-support-delivery.md`.

## Delivered behavior

Tutor cue detection inspects up to 40 earlier turns in the same learner, task and conversation context, within 30 days. An answer-only request can therefore be linked to an earlier request despite intervening discussion. Ordinary hint sequencing retains its existing behavior. The accepted turn stores the rule version, exact character offsets, related and inspected turn IDs, uncertainty and suggested reasoning action. Existing normal-priority assessor cases are reused per context and signal, including the previous combined-signal key. Staff evidence retains the original trigger and its preceding context plus up to 40 later turns in the same context, so later learner explanations remain reviewable without opening duplicate cases.

On submission, the producer inspects the retained answer, code and typed episode text, including fresh-stage content. It detects explicit copying/AI-boilerplate language and substantial exact reuse from the task's retained source passages or the learner's retained tutor hints. Each reuse match links a response field and exact character interval to the source passage/revision/approval or tutor-turn ID and its exact interval. The producer never retrieves another learner's work or uses an external plagiarism service.

Submission detection is bounded to the first 20,000 characters of each eligible field, 12 task source passages, and 40 earlier tutor turns within 30 days. Tutor comparisons use the same learner/task, reviewed task revision and assessment work reference when present. Exact reuse requires a contiguous run of 30 whitespace-separated tokens spanning at least 160 characters. Supplied task instructions, descriptions and starter-code runs are excluded. Recognition/reconstruction task answers (matching, sequencing, MCQ, multiple answer and quiz) are excluded from language detection, and those task types do not receive exact-reuse cues. These are inspectable engineering heuristics, not institutionally approved misconduct thresholds.

The accepted submission remains immutable. A separate cue snapshot uses the existing protected evidence-artifact store, without creating a learning-model evidence record. Assessed work routes immediately through its existing ASSESSMENT review source; practice routes through the accepted or safe-fallback FEEDBACK source when the feedback transaction completes. One case per response and signal survives submission and terminal retries. Practice that never reaches terminal feedback retains its cue snapshot but does not yet have a feedback-linked case.

The existing submission view includes a prompt to explain one reasoning step or make a prediction for a fresh example. The existing staff evidence endpoint returns the cue, exact retained response fields/conditions, relevant turns and source passages after its course-scoped access check. It preserves ordinary evidence responses for unrelated cases. This delivery changes no frontend contract or queue source kind and requires no new migration.

## Interpretation and remaining boundaries

Every cue explicitly allows quotation, permitted assistance, supplied templates and other explanations. Short code, short/common answers, unmatched text and excluded templates do not produce exact-reuse signals. A long legitimate quotation can still produce an uncertain review cue; staff must inspect the task conditions and hear the learner's explanation. The cue does not establish plagiarism, authorship, deception, disability, a diagnosis or a result. It never changes a pass rule, criterion decision, grade, reward, result release or penalty.

The detector does not recognize paraphrases, normalized/reformatted copies, arbitrary external solutions, every programming-language syntax, or material outside the recorded bounds. An absent cue is not evidence of independent work. Its usefulness and false-positive rate require evaluation with authorised human evidence. Actual queue owners and institutional response procedures still need genuine assignments. No such approval is supplied by the synthetic fixtures.
