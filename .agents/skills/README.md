# Skills

The harness provides four project skills:

- `$draft-implementation-plan` grounds current behaviour and writes `docs/plans/NNN-<slug>.md`.
- `$draft-pull-request` mirrors the plan and evidence in a draft PR.
- `$write-commit-message` writes conventional messages from the staged diff.
- `$create-agent-skill` creates concise, validated skills under this folder.

Each skill contains `SKILL.md` and matching `agents/openai.yaml` metadata. Detailed templates live only where the skill needs them.
